Traffic Accident Data Analysis & Visualization

This project analyzes traffic accident data to uncover patterns related to road conditions, weather, severity, and time of day. Using Python data analysis and visualization libraries, the project generates insights and an interactive-style dashboard to better understand accident hotspots and contributing factors.

Project Objective

The goal of this project is to:

Identify peak accident hours
Analyze accident severity distribution
Study the impact of weather conditions
Compare accidents across different road types
Visualize trends using charts and heatmaps

 How to Run
Install required libraries:
pip install pandas numpy matplotlib seaborn
Run the Python script:
python traffic_analysis.py
Generated files will be saved automatically in the project folder.
 Key Insights
Most accidents occur during peak traffic hours.
Clear weather has the highest accident count due to higher traffic volume.
Severe accidents are comparatively fewer but vary across weather conditions.
Urban and highway roads experience more accidents than rural roads.
